# Working on NoelOps

- Every PR that gets merged adds a short entry to the **Change notes** section at the bottom of `README.md` (newest first). Write it in the same PR, before merging.
  - Heading: `### <emoji> <Mon D, YYYY>: <short title>`, then a few plain-language bullets (bold for page or feature names).
  - Keep it Discord-friendly: no tables, no HTML, no links, under 2,000 characters per entry, so it can be copied straight into a Discord message.
  - Write for the crew, not developers: what changed and where to find it.
- The repo is public: never commit the Discord webhook URL, PIN hashes or other secrets.
