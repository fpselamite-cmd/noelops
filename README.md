# NoelOps (moved)

NoelOps now lives inside **ChosenOps HQ** at https://chosenops.web.app/noelops/ and its code is in the
`fpselamite-cmd/ChosenOps` repo (`hq/public/noelops/`). This repo only keeps the old address working: its page
sends you to the new one. Sign-in, data, backups and change notes are all in ChosenOps now.
